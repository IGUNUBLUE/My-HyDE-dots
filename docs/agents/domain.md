# Domain documentation

This is a single-context repository. Read `GLOSSARY.md` and relevant files in
`docs/adr/` when they exist. Create those documents lazily when terminology or
architectural decisions need recording; their absence does not block work.

Use the glossary's terms in specifications, tests and reviews. Surface conflicts
with existing ADRs before changing a decision.

Operational incidents and compatibility safeguards use this repository's existing
`memory/index.md` and linked records. Read relevant active records before changing
a component; keep this history authoritative rather than duplicating it in ADRs.
