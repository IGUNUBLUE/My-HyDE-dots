# Triage roles

Use these `Status:` values for incoming issues:

- `needs-triage`: awaiting assessment.
- `needs-info`: missing information.
- `ready-for-agent`: scoped and executable by an agent.
- `ready-for-human`: requires a human action or decision.
- `wontfix`: intentionally declined.

Implementation tickets may use `in-progress` and `done` to record execution.
Tickets produced from an agreed specification do not need triage again.
